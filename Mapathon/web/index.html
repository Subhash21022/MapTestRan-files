Methodology Summary

This project pairs ISRO/NRSC Bhuvan 1:50,000 Multi-temporal LULC satellite data (2005-06, 2011-12, 2015-16) with actual passenger flow counts harvested directly from the CMRL Public API (September 5 to September 6, 2026). Standardized to EPSG:32644, 800m pedestrian walking catchments were extracted across all 134 stations to compute built-up density, population, feeder bus accessibility, and street connectivity. Machine learning models (Random Forest and Negative Binomial GLM) were cross-validated via LOOCV to project Phase 2 station-level daily boardings.

Key Technical Tools

QGIS 3.x, GeoPandas, Shapely, Scikit-learn, Leaflet.js, OpenStreetMap, GHSL Population Grid, CMRL Passenger Flow API.
